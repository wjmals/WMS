## 배포 상태 및 남은 작업

- 코드 원격 HEAD: `2e42a20` (`fix: allow positive barcode outbound quantities`)
- Vercel signup UI: 승인 완료 관리자 안내 문구가 최신 번들에 포함됨.
- Vercel barcode UI: 출고 수량 부호 버그 수정은 아직 반영되지 않음. 최신 커밋 배포 완료 후 동일 Primary 품목에서 1 ea 출고를 재시험해야 함.
- Render health: HTTP 200, `database: configured`.
- Render signup guard: `4a5ca94` 이후에도 미승인 Beta 관리자 대상으로 창고지기 가입이 접수된 증거가 있음. 가입 순서 백엔드 수정은 Render에 아직 배포되지 않은 것으로 판정한다. 해당 probe 계정은 삭제하지 않고 pending으로 보존함.
- Groq Vision: Render 환경에 `GROQ_API_KEY`가 설정되지 않아 운영 비전 E2E가 차단됨.
- 배송 실조회: 실운송장 제공 후 유효/무효·제공자 응답·타임라인 저장을 재검증해야 함.
