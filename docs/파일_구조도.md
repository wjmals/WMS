# 저장소 구조

현재 주요 실행 경로를 요약한다. 세부 파일 목록은 실제 디렉터리를 기준으로 한다.

```text
wms/
├── README.md                 프로젝트 소개와 로컬 실행
├── package.json              루트 개발/빌드 명령
├── docker-compose.yml        PostgreSQL 16 개발 DB
├── start-wms.sh              로컬 통합 실행 스크립트
├── frontend/                 Next.js 웹 앱과 프록시
│   ├── app/                   화면 및 API Route Handlers
│   ├── components/            공통 내비게이션·승인 콘솔
│   └── context/               브라우저 인증 상태
├── rust-backend/              Axum API와 DB 연동
│   ├── src/main.rs             API 라우트·핸들러·업무 규칙
│   └── schema.sql              PostgreSQL 테이블·제약·기본 창고
├── admin_console/             별도 Python 관리자 도구
├── cv_client/                 Python 컴퓨터 비전 클라이언트
├── db/                        보조 MySQL 초기화 자료
├── docs/                      제안·기능·API·DB·파일 구조 문서
└── 재고 api/                  참고 자료
```

주요 화면 경로는 `/`, `/login`, `/signup`, `/barcode`, `/delivery`, `/monitor`, `/report`이며 각 페이지는 `frontend/app/` 아래에 있다. Next.js 프록시는 `frontend/app/api/` 아래에 있고, Rust API 상세 구현은 단일 `rust-backend/src/main.rs`에 있다.

보조 디렉터리는 주 애플리케이션과 실행 방식이 다를 수 있다. `admin_console/`과 `cv_client/`를 Next.js/Rust 서비스에 포함된 실행 프로세스로 간주하지 않는다. `db/`의 MySQL 초기화 스크립트도 현재 주 서비스 DB인 PostgreSQL 스키마를 대체하지 않는다.

`start-wms.sh`는 저장소 경로와 미리 빌드된 Rust 바이너리를 가정하므로 새 환경에서는 스크립트와 환경 설정을 확인한다. 자동 생성 결과물(`node_modules/`, `.next/`, `rust-backend/target/`)은 애플리케이션 소스 구조에서 제외한다.
