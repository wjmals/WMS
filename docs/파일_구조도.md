# WMS 파일 구조도

- 갱신일: 2026-09-23
- 기준: 현재 저장소 실제 디렉터리 구조

## 1. 최상위 구조

```text
wms/
├── README.md                 프로젝트 개요, 기술 스택, 실행 가이드
├── AI_LICENSE.md              AI 사용/라이선스 관련 문서
├── docker-compose.yml          로컬 PostgreSQL 컨테이너 구성
├── start-wms.sh                PostgreSQL + Rust API + Next.js 로컬 실행 스크립트
├── vercel.json                 Vercel 배포 설정(Next.js 프론트엔드만 빌드)
├── package.json                 루트 스크립트(frontend dev/build 위임)
├── docs/                       프로젝트 문서 모음
├── frontend/                   Next.js 14 웹 애플리케이션
├── rust-backend/                Rust Axum API 서버 (PostgreSQL 연동)
├── admin_console/                Python 관리자 콘솔(Streamlit)
├── cv_client/                    Python 컴퓨터 비전 클라이언트
└── db/                           MySQL 초기화 스크립트(보조)
└── 재고 api/                      수산물 재고 관련 참고 자료(PDF/엑셀)
```

## 4. `rust-backend/` — Rust API 서버

```text
rust-backend/
├── Cargo.toml / Cargo.lock       의존성 정의(axum, sqlx, reqwest, argon2 등)
├── Dockerfile                    포터블 컨테이너 빌드
├── schema.sql                    PostgreSQL 테이블 정의 및 기본 창고 시드
├── .env / .env.example           DATABASE_URL, PORT, GROQ_API_KEY
├── README.md                     로컬 실행 및 배포 가이드
├── src/
│   └── main.rs                   전체 API 라우트, 핸들러, 비즈니스 로직
└── target/                       Cargo 빌드 산출물(로컬 전용)
```

## 5. 기타 폴더

| 폴더 | 역할 |
|---|---|
| `admin_console/` | Streamlit 기반 별도 관리자 콘솔(Python). `app.py`, `requirements.txt` |
| `cv_client/` | 카메라 텔레메트리용 Python 컴퓨터 비전 클라이언트 |
| `db/` | MySQL 초기화 스크립트(`mysql_init.sql`). 현재 운영 DB는 PostgreSQL이며 이 폴더는 보조 자료 |
| `재고 api/` | 수산물 재고 동향 관련 참고 문서(PDF, 엑셀) |

실제 운영 백엔드는 `rust-backend/`이다.
